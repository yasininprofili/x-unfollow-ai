# X Unfollow AI: Clean Up Your X (Twitter) Following List and Unfollow Non-Followers

X Unfollow AI is a free Chrome extension for managing your following list on X (Twitter). It shows which accounts do not follow you back and lets you unfollow them in bulk at a speed you control, while a whitelist protects the accounts you want to keep.

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/jndpmkphjiekodbohclijofkbajjglpi?utm_source=github&utm_medium=readme&utm_campaign=x_unfollow_ai)** | **[Full guide and FAQ](https://www.addonschrome.com/extensions/x-unfollow-ai-manage-your-twitter-following-list.html?utm_source=github&utm_medium=readme&utm_campaign=x_unfollow_ai)** | **[Video demo](https://www.youtube.com/watch?v=RNkjPqaRssY)**

This repository is the public home for X Unfollow AI documentation, release notes and the issue tracker. The extension itself is distributed through the Chrome Web Store.

## Features

- **Find non-followers:** see who you follow that does not follow you back
- **Bulk unfollow:** unfollow everyone, or only the accounts that do not follow back
- **Whitelist:** protected accounts are never unfollowed
- **Speed controls:** set the pace yourself
- **Statistics:** daily, weekly and total unfollow counts, plus an operation history
- **Excel export**
- Interface in 10 languages: English, Turkish, Spanish, French, German, Portuguese, Italian, Russian, Japanese and Chinese

## How to use it

1. Install X Unfollow AI from the [Chrome Web Store](https://chromewebstore.google.com/detail/jndpmkphjiekodbohclijofkbajjglpi?utm_source=github&utm_medium=readme&utm_campaign=x_unfollow_ai).
2. Open X in Chrome while signed in.
3. Open the extension and choose the mode: all accounts or only non-followers.
4. Add the accounts you want to keep to the whitelist.
5. Pick a speed and start. You can stop at any time.

The [full guide](https://www.addonschrome.com/extensions/x-unfollow-ai-manage-your-twitter-following-list.html?utm_source=github&utm_medium=readme&utm_campaign=x_unfollow_ai) explains the filters and settings.

## Keep your account safe

X limits how fast an account can follow and unfollow, and its rules prohibit aggressive, bulk follow churn. A tool does not change that. Use the slow speed, work in small batches spread over several days, and stop if X shows a warning.
